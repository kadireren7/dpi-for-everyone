dpi-for-everyone - macOS quick start (Beta)
===========================================

Built for macOS 11 or newer (tested on macOS 14, 15 and 26). Nothing
to build or download besides this package: no Xcode, Homebrew, Git or
Python needed. Apple silicon (M1/M2/M3/...): the -arm64 package;
Intel Macs: the -x86_64 package.

BEFORE YOU START
  Quit other DPI tools (SpoofDPI, ByeDPI, zapret/tpws, GoodbyeDPI-like
  apps) and VPN apps that filter traffic. Two such tools at once
  interfere with each other.

INSTALL (recommended: double-click)
  1. Extract the package (double-click the .zip file).
  2. Double-click Install.command. It opens in Terminal and asks for
     your Mac password (sudo) - that is expected, it is installing a
     system service. If macOS says the file is "from an unidentified
     developer", right-click (or Control-click) it and choose Open
     once instead of double-clicking.
  3. Check: in any Terminal window,
         dpictl status
     You should see "Service: Running" and "Protection: Active".
  4. Open Safari, Chrome, Firefox, Discord, ... normally. No proxy
     settings, no DNS changes, nothing to configure in any app.

INSTALL (advanced/manual: Terminal)
  cd into the extracted folder and run:
         sudo ./install.sh

IF SOMETHING FAILS
         dpictl doctor
         dpictl diagnose discord.com
         dpictl logs
         dpictl support-bundle
  dpictl support-bundle writes a redacted diagnostics .tar.gz you can
  send to whoever gave you this package (no telemetry - it only ever
  writes a local file; nothing is sent anywhere automatically).

EVERYDAY COMMANDS
         dpictl status
         dpictl status --verbose
         dpictl doctor
         sudo dpictl stop       (normal internet, no bypass)
         sudo dpictl start
         sudo dpictl restart

  dpi-proxy-ctl still works with the same commands (a compatibility
  alias for dpictl).

UNINSTALL
  Double-click Uninstall.command (in the extracted folder), or
  manually, in the extracted folder:
         sudo ./uninstall.sh
  Removes everything: the service, the programs, settings, logs and
  dpi-proxy's firewall (PF) rules. Add --purge (manual only) to also
  remove /usr/local/etc/dpi-proxy.

This is a beta: it passes a full automated end-to-end test on real
macOS runners in CI (PF, launchd, root), but it has not yet been
tested on a physical Mac or against real ISP DPI. It is not a VPN and
never decrypts traffic. How it works: it adds its own rules to the
built-in macOS packet filter (PF) - in its own section, leaving
everything else alone - so this Mac's HTTPS and DNS go through the
local dpi-proxy service; when the service stops or crashes the rules
are removed and the internet works as before.
